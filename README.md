# 🎮 Gaming Store Website

A modern and responsive **Gaming Store Homepage** built as a web development practice project.

## 📌 Project Status

🚧 **Currently in Development**

At the moment, this project contains **only the homepage**. Other pages and features will be added in future development.

## 🏠 Current Homepage

The homepage includes:

* 🎮 Gaming-focused hero section
* 🕹️ Featured gaming content
* 🔍 Search interface
* 🎨 Modern dark gaming design
* ✨ Hover effects and animations
* 📱 Responsive layout
* 🎯 Call-to-action sections
* 🧭 Navigation bar
* 🖼️ Gaming images and cards

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Tailwind CSS
